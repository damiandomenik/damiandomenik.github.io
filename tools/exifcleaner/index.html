Photo metadata

Your photos are carrying more than the picture.

Most cameras and phones write a hidden record into every file: where you were, to the metre. When you took it, to the second. Which device, down to its serial number. Sometimes your name. Drop a photo below to read that record — then strip it out.

How this works

Nothing is uploaded
Your files are read by JavaScript in this tab. There is no server to send them to, and no third-party code involved — the metadata parser was written for this page rather than pulled from a CDN.
The image is never re-compressed
Cleaning happens at the container level: JPEG marker segments, PNG chunks, WebP RIFF chunks. The compressed image data is copied across byte for byte, so a cleaned photo is pixel-identical to the original. Tools that redraw the image through a canvas quietly cost you quality on every pass.
The orientation flag is kept, on purpose
Stripping everything also strips the flag telling viewers which way up the photo goes, which is why so many cleaned phone photos end up sideways. A 36-byte block containing that single tag is written back. It identifies nobody. You can turn it off.
One button, and only that button, leaves the browser
Where a photo has GPS data, the coordinates are shown as plain numbers and no map is embedded — loading map tiles would send your location to a provider before you had decided anything. If you want to know what is actually at those coordinates, there is a button that asks OpenStreetMap. It sends the coordinates and nothing else: no photo, no filename. It never fires on its own, and the rest of the page never touches the network.
