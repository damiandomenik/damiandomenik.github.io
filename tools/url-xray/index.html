URL X-RAY

What happens when you enter a URL?

See the hidden journey behind every website request — the lookups, handshakes and downloads your browser performs before a single pixel appears.

A browser can't measure DNS or TLS timings for someone else's site — the security model forbids it. So this tool is honest about it: Trace measures what it really can, X-ray this page reads genuine timings from the page you're on, and Demo replays a prepared dataset. Nothing is invented, and no URL leaves your browser except as a request to the site itself.
