URL X-RAY

What happens when you enter a URL?

See the hidden journey behind every website request — the lookups, handshakes and downloads your browser performs before a single pixel appears.

A browser can't measure DNS or TLS timings for someone else's site — the security model forbids it. So this tool is honest about it: Trace measures what it really can, X-ray this page reads genuine timings from the page you're on, and Demo replays a prepared dataset. Nothing is invented, and every reading says where it came from. A trace looks up DNS through Cloudflare's public resolver and fetches the page through a free public relay, so those two services see the address you type.

URL X-Ray has no backend and no account. A live trace makes two outbound calls: a DNS lookup to cloudflare-dns.com, and one page fetch through a public relay (AllOrigins, falling back to CodeTabs) because a browser may not read another site directly. Both see the address being traced. Nothing is logged or stored here.
