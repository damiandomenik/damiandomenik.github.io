    Where the webcams come from

    This page has no server of its own, so it cannot hold an API key for you. Windy's Webcams API only accepts a key as a request header, and any key shipped with a static site would be readable by anyone who opened it.

    You can paste your own free key below. It is kept in this browser only, it is never sent anywhere except to api.windy.com, and you can remove it at any time. Without a key the globe runs on a small demo set, labelled as such.

    Get a key at api.windy.com/keys. Free keys have a domain restriction — add this site's domain there, or requests from the browser will be refused. Preview image links from the free tier expire after about ten minutes, so they are re-fetched on every load.
