RIFTRUSH

Competitive Multiplayer Parkour Dungeon Racer

Ohne Server spielen (zu zweit) Damit andere deine Lobby sehen können, braucht es eine gemeinsame Stelle im Netz — einen Signaling-Server. Vorlagen dafür liegen in /server, das Aufsetzen dauert ein paar Minuten. Ohne Server geht nur die Direktverbindung: ihr tauscht einmalig einen Verbindungscode aus.
Verbindungs-Einstellungen
Einmal eintragen → alle sehen die offenen Lobbys und treten per Klick bei. Vorlagen zum Aufsetzen liegen in /server.
